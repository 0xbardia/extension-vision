# Privacy

Extension Vision is designed for personal local use.

- API keys remain inside the user's browser in local extension storage.
- A screenshot is transmitted only to the AI provider selected by the user.
- Screenshots are held in memory for the active request and are not stored.
- There is no analytics, telemetry, tracking, advertising, or hidden network request.
- Local settings remain local to the browser.
- The extension does not analyze a page unless the user explicitly starts a solve with Alt + Q or a visible control.
- The extension does not click, submit, or alter the analyzed webpage.

Provider terms and privacy policies apply to requests sent to OpenRouter or OpenAI. Do not submit sensitive pages unless you understand the provider's handling of image inputs.
