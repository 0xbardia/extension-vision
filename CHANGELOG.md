# Changelog

All notable changes to Extension Vision are documented here.

## [0.2.0] - 2026-07-23

### Added

- Prompt presets: Quiz Solver, Page Summary, Translate Visible Page, Explain Screenshot, Extract Information, and Custom.
- Processing-stage feedback, cancellation, response timing, and provider/model metadata.
- Copy Answer, collapsible settings, result preservation, and expanded result controls.
- Safe migration of v0.1.0 prompt settings.

### Maintained

- Alt + Q, Side Panel, visible-tab capture, OpenRouter, OpenAI Direct, structured JSON parsing, and local settings.
